## 问题与修复

在已登录 Electron 的「云文档」实际点击检查中，目录里每个文档都显示为禁用按钮，更新时间为空。真实 `/api/im/library` 返回 `room_ids` 数组和毫秒数 `updated_at`；旧迁移适配器只取 `room_id` 字符串和字符串时间，导致丢失上下文。

`LegacyClient.documents` 现在使用服务端返回的首个有效 `room_ids` 作为可打开的所属群，同时兼容原有 `room_id`。只选服务端已返回的上下文，不自行遍历或创造群权限。有效毫秒时间转换为 ISO 日期；无所属群或非法时间仍保持空值，不编造时间与来源。
