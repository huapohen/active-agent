## 实现

桌面后台使用 64 逻辑像素顶部管理栏，包含火箭标志、管理后台名称、可用功能导航搜索、导出、刷新和真实企业/当前管理身份。搜索仅索引现有七个管理目的地，支持“Agent”“人类”“组织”“角色”等关键词；选择结果直接打开现有页面。搜索不宣称覆盖成员私有资料或全局数据。

后台可用区域达到 760 时显示分组侧栏；760–999 时展开宽 176，较宽区域为 200，可以收起到 64 宽图标栏。组织架构、应用管理和管理记录分组可展开/收起；通过搜索切换页面时会展开对应分组。600–759 区域保留可横向滚动的导航页签；小于 600 保留手机管理首页和返回行为。

概览将企业名称、企业编号、总人数、部门数、所有者和管理员统计集中到顶部身份卡。人类/Agent 数量和成员状态来自企业概览响应，不能从当前筛选页推算。其他卡片承载现有成员、部门、组织、应用、权限与审计入口；没有生成认证状态、付费额度、待办账单或活跃曲线。

成员区使用浅灰外背景和白色内容面板，增加独立标题/说明区；宽度达到 600 时保留 210 宽部门树，右侧表格可横向滚动。表头字号由 11 调至 13，成员名称 14，圆形头像、现有操作及职业/职位、组织信息继续保留。手机成员列表头像 44、名称 17；手机管理主页条目 17、说明 14、分组 13。部门筛选仍为直属成员，不暗改成累计子部门人数。

## 权限和协议

本批没有修改企业 HTTP/MCP 协议。所有数据和变更继续通过 `EnterpriseState`、服务端管理角色和现有能力校验；人类与 Agent 使用同一管理入口和请求。新增导航搜索在派发时检查当前工作身份，捕获的旧身份回调不能打开新目的地。

部门、成员、组织、应用策略、角色和审计操作保持原有行为，包括版本冲突、保留输入、成员详情前后导航和最后所有者保护。侧栏折叠/分组展开是当前视图状态，尚未新增跨端持久化或协议设置。
