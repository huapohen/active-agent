## 行为与协议

实现位于 `apps/office/lib/ui/desktop_navigation.dart`，复用现有 `OfficeNavigationItem` 与 `officeNavigationItems`。

| 接口 | 行为 |
| --- | --- |
| `officeDesktopNavigation(state, [configured])` | 解析当前身份的 `desktop_nav`；维持用户顺序、排除未知或重复项与 `enterprise`，空或无效配置使用默认导航 |
| `showOfficeDesktopNavigationEditor(context, state)` | 增加、移除、拖动/箭头排序、恢复默认；至少保留一项，最多十二项；本地草稿只有明确保存才写入 |
| `showOfficeDesktopNavigationMenu(context, state, item, position: ..., onOpen: ...)` | 锚定打开位置显示快捷菜单；固定项可打开、进入编辑器，不能移动或移除 |

默认十二项依次为：消息、Agent、通讯录、云文档、任务、工作台、视频会议、日历、邮箱、考勤、审批、人机妙记。企业管理由主框架按权限提供独立入口，不进入桌面个人导航配置。固定“设置”项不在 `desktop_nav` 中，上移、下移和移除均不可用。

保存仅通过现有 `state.saveSettings({'desktop_nav': [...]}, baseRevision: ...)`，因此人和 Agent 使用同一身份协议与设置版本。此文件不更改手机底栏、应用授权、工作台收藏或企业权限。未实施的侧栏触发与恢复入口由主线负责接入。

## 草稿、失败与身份保护

- 打开编辑器或快捷菜单时捕获当前导航、设置 `revision`、连接端点、principal ID 和 `identityGeneration`。
- 菜单的移动/移除根据打开时的完整列表构造明确目标；请求失败后再次点击同一动作提交相同目标，不会连续移两次或改动新列表中的其他项。
- 普通失败展示实际错误并保留目标；409 暂停后续直接保存，菜单可携带原草稿进入编辑器恢复。
- 冲突后明确“读取最新设置”，显示服务器导航；可以采用服务器导航，或保留自己的导航并采用最新版本继续编辑。两条路径均不会自动保存，仍需明确点击“保存”。
- 临时断网保留草稿与本地编辑能力，禁止保存和远端读取；重连后恢复保存。菜单打开本地应用仍可用。
- 端点、身份或身份代次变化时永久锁定旧会话并清空旧草稿、错误和读取结果；A→B→A 不会复活旧菜单。晚到的读取结果不恢复旧页面。
- 编辑器可在保存等待中关闭；请求结束不会关闭底层页面。自动关闭还检查目标 route 是否仍为当前页。
