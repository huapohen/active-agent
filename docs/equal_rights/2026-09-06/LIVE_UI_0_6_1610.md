## 发现并修复的问题

第一次显式“结束编辑会话”后立即关闭浏览器标签，触发 `/collab` TCP 代理 clientSocket 未处理的 EPIPE，Node 退出。根因是仅监听 upstream 错误。修复为两侧 error/close 都回收该隧道，连接前检查已断开的客户端；不会吞掉文档持久化错误或将业务失败伪装成功。

独立自动化回归覆盖 8 轮撤销单文档会话后突然断开 WebSocket，验证原进程健康、已撤销能力返回 401、另一成员继续写入、后续新成员双向同步。专项 editor/actions/collab 共 18 项通过，编辑器专项 223 次真实 HTTP 加 WebSocket。

修复后真实浏览器再次退出设计会话，服务保持健康，工程端能继续写入。另发现 Web 在异步取得 ticket 后打开新标签可能受弹窗限制。最终修复为在点击内同步预开空窗口、清除 opener，再取得 ticket 并导航；失败只关闭该空窗口，保留 IM 标签和内存登录。

16:19 的最终真实 UI 复验连续三次点击“协作编辑器”，前两次执行“结束编辑会话”并关闭，第三次保留页面。三次均正常打开同一文档，原 IM 始终保持登录，标题与 r4 正文保留，包括“退出同伴后，工程仍可继续编辑”。服务始终健康。最终截图 `output/playwright/renji-060-doc-final.png`。当前 Flutter 完整 48 项测试通过、analyzer 无问题，Web 实际编译成功；Mac/iOS 最新热重载分别约 527/396 ms。

退出回归包含 4 轮 WebSocket terminate 与 4 轮 TCP reset。临时副本撤掉代理修复后明确失败，修复版通过。最终 Doc Free 全量 **193 项通过**，不是把与全量重叠的专项数量相加。

本次不验证大型文档性能、移动富文本输入法、离线文档或生产 TLS。实际群消息与文档均为用户授权的虚构公司模拟内容；没有向真实飞书企业发送消息、审批、邮件或更改管理配置。
