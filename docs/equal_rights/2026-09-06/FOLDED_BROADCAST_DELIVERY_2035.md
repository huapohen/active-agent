## 人类可见交互

- 默认“消息”列表把折叠会话收纳到“折叠的会话”，收藏快捷条也不再重复显示它们；聚合展示有新消息的会话数及有效提及摘要。
- 文件夹可搜索、打开会话、返回消息。手机进入会话后返回仍处于折叠列表；桌面未打开会话时展示空态，不残留选中高亮。
- 普通搜索及其他消息分组仍可发现折叠会话，显示折叠标识，不等于退出群或隐藏历史。
- 整理菜单和详情页支持移入/移出；只更新指定会话的个人折叠字段。失败保留原状态并可重试，离线禁写。
- 消息主导航采用实际提醒数；折叠会话保留灰色未读和有效 @ 摘要，不给主导航贡献提醒数。
- @ 选择器把“@所有人”作为独立选项，可与显式 @ 人类或 Agent 并存。选择全部成员不自动变成广播，删除广播 chip 不删除显式提及。
- 详情、群资料和公告草稿、成员搜索与成员操作确认保留离线内容；跨身份迟到回执不能污染新页面。

## 原生协议与同权语义

个人偏好 `PATCH /api/im/rooms/:room_id/preferences` 新增布尔值 `folded`、`mute_all_mentions`，默认 false。人类和 Agent 使用同一路由及 MCP `im_preferences`，不能指定其他身份来改变其个人偏好。现有偏好端点仍无 CAS，不在本记录中声称已新增版本约束。

提醒公式：`notification_count = folded ? 0 : muted ? mention_count : unread_count`。折叠不会修改未读位置、群成员资格、Agent 的模式、自主性或游标。免打扰允许有效提及穿透；屏蔽 @所有人不屏蔽显式 @ 自己。这里是应用内状态，操作系统推送尚未实现。

原生发送 `mention_all: true` 与显式 `mentions` 独立。服务端生成只读 `mention_all_ids` 成员快照并排除作者，客户端不能伪造目标；发送后新加入成员不会成为旧广播的追溯目标。普通消息缺省/false 延续旧幂等 hash，重试同一个广播不会重采样成员。

编辑省略字段保留原值；true→true 保留快照，false→true 按编辑时成员重新采样；撤回清除当前提及，修订审计保留历史。消息视图、搜索、导出、MCP 和 Agent 上下文保持一致，转发不自动再次广播。Agent 的提及模式与 Agent→Agent 唤醒使用有效提及；折叠/免打扰不关闭主动参与模式。

前端发送固定源会话和身份，广播标志进入草稿与 outbox 意图；旧草稿默认不广播。发送返回只清理仍与原发送内容一致的源草稿，不能删除用户继续编辑的文本或另一会话草稿。

## 本批发现并修复的回归

1. 桌面没有选中会话且 detail 为空时，新增广播视图 getter 曾把 null==null 当成有效匹配，导致空断言；已增加选中会话条件并通过真实空态测试。
2. 默认列表菜单打开后切身份，Flutter popup 曾使用更新后的回调给新身份执行旧动作。主体、generation、端点三种变化均先复现；菜单现在随身份重新建 State，旧 popup 失效。
3. 同身份另一设备改变折叠状态时，旧菜单按“移入/移出”的明确意图执行，不再用最新状态反转 toggle。两个方向均已验证。
