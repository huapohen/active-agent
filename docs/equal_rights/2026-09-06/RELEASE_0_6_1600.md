## 本轮可使用的内容

产品展示名统一为 **人机**，五端使用火箭图标。工程内部名称与 bundle ID 保持兼容。Mac 与 iPhone 模拟器运行真实 Flutter Debug 客户端，修改 Dart 后可热重载；它们连接同一个本地 Doc Free 服务，最初使用不同身份完成多人验证；用户之后将模拟器改为 huapohen，当前 Mac 与模拟器保留该登录。

商店保留 100 个明确职业模板，新增机伴与机伴·手机，共 102 个模板。默认真实 Agent 好友为 activate-agent 与机伴。模板包含职业、职位、能力指令和来源组织，安装后是独立的 Agent 同事。企业目录支持组织创建、修改、删除保护、版本冲突检查、成员岗位，以及来源公司和当前任职组织分别展示。**组织目录尚不提供多企业租户隔离。**

主动性配置属于每位同事：参与模式、是否允许自主行动、每轮动作数、可用动作、复核间隔。执行器根据任务、文档、日程和到期复核发现工作，保存可检查的上下文、冻结动作计划，再逐步取得真实服务端回执。文档创建/更新、任务创建/更新、联系人和日历相关动作共 8 类。限制、租约、因果预算和幂等回执阻止旧执行覆盖新状态；推理本身不承诺 exactly-once。

本轮三位 Agent 各用自己的身份做了一次真实 `gpt-6-astra / medium` 调用，产生 **8 条 committed 动作回执**：3 篇共享文档、3 项交给真人的任务、2 次自身任务更新。触发来自待办复核和文档变化，不要求人先 @。这是 3 位同事、8 次动作的实际验证，不是 100 种职业全部验收或长期无人值守证明。详见 [真实模型报告](REAL_COMPANY_MODEL_1546.md) 和 [模拟公司与协议范围](COMPANY_AUTONOMY_1603.md)。

## 文档就是共同载体

普通会话成员可从文档窗口进入 **协作编辑器**，使用同一份 Doc Free 正文、标题和版本。页面包含富文本格式、大纲、共同光标、在线身份和 Markdown 导出；原有 Markdown 版本冲突与草稿保护继续保留。人类编辑与 Agent 动作回执落到同一个权威协作状态。

编辑入口使用 60 秒一次性 ticket，兑换 30 分钟的单文档能力；源 IM 凭据不会交给文档页面。账号退出、移出会话、停用应用或取消文档共享后，已有连接也必须重新验权，入站写入与出站内容均被阻断。编辑不能改写 Agent 动作回执、受保护契约或未知 Yjs 根。

Agent 文档写入采用持久意图与 CRDT 内回执恢复。客户端更新先落盘，再广播；隔离进程 SIGKILL 验证确认收到更新的同伴所见正文能从磁盘恢复。IM JSON 与 CRDT 文件不是跨文件原子事务，文档步骤通过恢复协议收口。

双人真实浏览器验收记录见 [多端界面与文档验收](LIVE_UI_0_6_1610.md)。富文本仍没有完整表格、内嵌图片、离线编辑、完整修订比较和飞书全部文档能力；不把当前编辑器描述为已经全面超越飞书文档。

## 新增界面与办公流程

手机底栏保留消息旁 Agent 入口，可保存个人常用功能与排序；头像打开我的、账号设备、设置和企业管理。实际从手机将人机妙记加入底栏，保存后读取服务端 revision 2，打开同一份四段妙记，再恢复默认底栏。详情见 [本批跨端验收](UI_COLLEAGUES_MINUTES_1727.md)。

人机妙记提供文字导入、录音附件、逐字稿编辑、共同纪要、Agent 待办与 Markdown 导出。Web 创建并保存真实记录，Mac 与 iPhone 读回 r4、四段正文、一份共享文档和一项 Agent 待办。录音转写尚未配置；当前 no-worker 演示服务只分配任务，不伪称任务已经由模型整理完成。

每位 Agent 的人格入口提供所选工作会话的主动参与、仅响应和暂停，以及独立自主动作开关；尚无跨会话默认人格编辑。机伴有独立动画光标与真实能力卡；隔离浏览器执行原型支持异步 API 与并行会话，已通过合成 Chrome 验证，但尚未接入 IM 执行器或系统级手机/桌面控制。参见 [机伴原型记录](COMPANION_BROWSER_1721.md)。

消息旁三条杠现展开桌面分组列或手机抽屉。个人标签支持名称规则、批量归入人类/Agent会话，编辑分组可设置侧栏显隐、分区排序与独立常用快捷项。真实 Web 创建标签、自动与手工归入两个混合群，Mac和iPhone实时读回；activate-agent另以自身MCP身份创建自己的分组，不修改人类偏好。详见 [真实分组验收](MESSAGE_GROUPS_LIVE_1745.md)。

## 五人公司，保持低资源占用

`scripts/demo_office_company.py` 通过公共 IM API 幂等创建虚构公司、5 位人类和 3 位 Agent，共用一个群聊与文档。账号放在被忽略的 `data/office/demo-company.json`，不进提交。

| 人类角色 | 已登录界面 |
| --- | --- |
| 所有人 huapohen | Mac Flutter 应用与同账号 iPhone 模拟器 |
| 产品成员 | Chromium 独立上下文 4（430px 移动布局）；原模拟器由用户切回 huapohen |
| 工程成员 | Chromium 独立上下文 1 |
| 设计成员 | Chromium 独立上下文 2 |
| 运营成员 | Chromium 独立上下文 3 |

网页上下文隔离凭据与会话；不等于在一个登录里切换显示名。没有同时启动多个手机模拟器，也没有启动 100 个模型 worker。执行器只调度实际在会话中的活跃 Agent，worker 与模型并发分别可配置。真实模型验收完成后本地保留 `--no-worker` 服务，避免演示时不断产生模型费用；启动常驻 fleet 才会继续自动领取后续工作。

## 办公、鉴权与协议

本轮按实际飞书手机、桌面、企业后台观察补充：手机聊天四列功能网格、展开编辑器、移动企业管理分区、职业商店、组织成员岗位、服务端高级搜索、快捷键搜索、Agent 策略与执行记录。成功动作数量只依据可信服务端消息关联和回执显示，人类仿造文本不会变成成功状态。

鉴权已有可配置本地账户与 OIDC authorization-code / PKCE，显式绑定现有身份、统一撤权和服务端 provider 配置。隔离 issuer 测试通过；**尚未连接真实企业身份提供方**。REST、MCP 与受限 A2A 网关共享业务权限，但真实模型动作本轮通过 REST 执行，不把这份证据扩写成所有操作已完成 MCP/A2A 端到端验证。

[飞书实看对照](FEISHU_LIVE_DEEP_COMPARISON_1530.md) 记录管理员和员工身份差异、手机 @ / + / 搜索、设置、工作台、审批、邮箱、预加入会议及企业后台。本轮手机镜像已可用，过去“手机企业后台未验证”的笼统结论已由这份具体观察取代。观察范围与本项目实现范围分别记录。
