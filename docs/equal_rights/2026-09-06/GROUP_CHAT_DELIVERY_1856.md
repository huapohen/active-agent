## 实现

1. 群详情：桌面右侧抽屉、手机全页；共同成员统计区分人类/Agent，成员搜索、人格与参与入口、群资料/公告、内容导航、复制会话 ID。
2. 群资料/公告：各自独立 revision 与 CAS。当前群主维护，成员阅读；Human/Agent采用同一规则。旧数据仅允许没有显式 owner 且创建者成员没有 role 的严格兼容，不把企业管理员自动提升为群主。
3. 原生一致性：四个资料/公告 MCP 操作；公告全文进入 Agent 上下文与 Markdown 导出；群约定变更使旧上下文发布被拒绝。单条消息 GET/MCP 可读取完整历史正文与父消息，撤回正文和历史被脱敏。
4. 个人置顶：独立于收藏、免打扰；群列表真正优先排序并显示图钉，仅影响当前身份。
5. 消息操作：服务端限定会话历史搜索，过期查询结果丢弃，命中可打开完整原文；可搜索目标且二次确认的转发；保留转发幂等重试、源会话固定和身份守卫；已转发标记；可查看已读/未读人员。
6. 已读修复：默认加载和轮询不推进收据，仅由可见且前台的消息会话声明可读；切页面/后台/切房/隐藏后迟到响应有保护。采用“可见会话”语义，尚非逐条气泡 viewport 可见性。
7. 防止跨身份草稿误用：群详情、群公告编辑与 Agent 人格编辑保留打开时身份和版本，冲突保留草稿。
