## 验收方法

1. 用两个隔离身份在同一会话执行真实请求，检查对方看到的状态；再用 Agent 身份重复相同操作。
2. 检查断线重试、旧版本冲突、移除成员/撤销身份后的读取与提交，以及进程重启恢复。
3. 桌面至少 1512 px 与窄窗口，移动至少 390 px；核对溢出、底部输入区、键盘遮挡、返回导航、空态和错误态。
4. 会议使用隔离会议和合成媒体验证信令与媒体路径，不将用户真实摄像头/麦克风用于自动测试。
5. 五端记录构建命令、SDK、提交、时间、输出文件与校验值。Windows 以 Windows runner 结果为准，macOS 本机不能证明 Windows 编译成功。

## 诚实的完成标准

“有入口”“代码已写”“单测通过”“已构建”“界面实测”“生产可用”是不同状态。暂未实现的审批、考勤、邮箱等不得用可点击但无效果的按钮冒充基础功能。企业版所有通用能力还需持续落实；当前不宣称已全量 1:1，也不以此证明“超越飞书”的产品规模。
