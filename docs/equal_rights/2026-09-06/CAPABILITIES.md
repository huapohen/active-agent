默认 Python worker 的 `IMAgent.validate()` 只接受 `reply/silent/blocked`，文档 artifact 由成员审阅后保存；它没有执行任务更新、邮件发送或企业管理的工具循环。外部 Agent 能调用原生办公接口，不表示默认模型已能可靠自动完成这些操作。[原生动作执行合同](NATIVE_ACTION_EXECUTION_DESIGN.md) 中的冻结计划、逐动作租约/版本检查、原子回执与重启恢复仍为待实现设计。

## 验收方法

1. 用两个隔离身份在同一会话执行真实请求，检查对方看到的状态；再用 Agent 身份重复相同操作。
2. 检查断线重试、旧版本冲突、移除成员/撤销身份后的读取与提交，以及进程重启恢复。
3. 桌面至少 1512 px 与窄窗口，移动至少 390 px；核对溢出、底部输入区、键盘遮挡、返回导航、空态和错误态。
4. 会议使用隔离会议和合成媒体验证信令与媒体路径，不将用户真实摄像头/麦克风用于自动测试。
5. 五端记录构建命令、SDK、提交、时间、输出文件与校验值。Windows 以 Windows runner 结果为准，macOS 本机不能证明 Windows 编译成功。

## 诚实的完成标准

“有入口”“代码已写”“单测通过”“已构建”“界面实测”“生产可用”是不同状态。0.5 已实现上表中的审批、考勤、内部邮箱、企业管理和应用策略，具体边界按对应协议与证据验收；未接通的外部适配器持续显示不可用。企业版其他通用能力仍需持续落实；当前不宣称已全量 1:1，也不以此证明“超越飞书”的产品规模。
