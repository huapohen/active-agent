## 可用设置与协议

| 设置 | 实际效果 |
| --- | --- |
| `message_alignment` | 消息左对齐或自己在右、同事在左 |
| `text_scale` | 全局 85%–130% 文字比例与预览 |
| `send_shortcut` | Enter 或 Ctrl/⌘+Enter 发送；保留换行和输入法保护 |
| `show_message_preview` | 控制会话列表最近消息正文是否可见 |
| `mobile_nav` | 人类与 Agent 各自的底栏排序与功能选择，保留“更多”入口 |
| `time_format` | 新增 `24h` / `12h`，默认 `24h`；改变显示，不修改已存时间戳或时区 |

时间制接入会话列表、消息时间、原文查看、文档列表、日程、会议、邮箱、审批、考勤、企业目录和工作回执等现有时间格式化入口。12 小时制正确区分上午/下午、午夜与正午；固定北京时间的考勤说明保留原有业务时区。

原生接口为 `GET/PATCH /api/im/settings`，写入需要 `base_revision`。MCP 使用 `office_settings` / `office_update_settings`，新增枚举有明确 schema。每个工作身份独立保存，偏好不授予管理权限。旧存储只读时补默认值，不重置既有偏好或修订号。

设置遇到 409 时保留当前状态，提供“读取最新设置 → 采用最新设置，重新选择”；底栏编辑仍可保留个人排序并显式采用最新版本。账号、会话和设置迟到响应不再回填另一个身份。身份代次、端点或主体改变时，旧设置/账号/底栏页面永久锁定，密码草稿清空；同身份临时离线仅禁写并保留草稿。
