## 默认 Agent 好友与主动能力

重启开发服务时显式采用已有 Agent 的确切身份 ID，保留身份、凭据和工作历史；不按展示名猜测或覆盖用户自建同事。以 huapohen 的真实身份读取 `/contacts`，返回两个默认好友：`activate-agent`、`机伴`，对应系统标记 `activate-agent`、`desktop-companion`。共享会话中的其他 Agent 仍可见。

所有 Agent 均可进入人格与参与设置；当前配置范围是所选工作会话。参与模式（主动、仅响应、暂停）与是否允许自主动作分离。不存在“只有 activate-agent 才能主动”的代码条件；全局默认人格字段尚未实现。

机伴的界面身份标记有独立指针动画，但这不是系统鼠标正在受控的状态。设备能力卡明确区分已安装同事、待连接运行环境和不支持的系统操作。独立浏览器执行服务的具体测试见 `COMPANION_BROWSER_1721.md`。

## 头像与可编辑底栏

手机头像实际打开“我的”侧面板，包含工作身份、公司、账号、我的账号与设备、个人设置、工作台、编辑手机底栏、企业管理和退出。企业管理入口来源于当前身份的服务端管理权限。

在“编辑底栏”实际移除工作台、添加人机妙记并保存，服务端 `/settings` 读回 revision 2 和 `messages, agents, docs, minutes`。底栏即时改变，点击人机妙记打开同一份跨端记录。随后通过“恢复默认底栏”并保存，恢复 `messages, agents, docs, workbench`，保留用户原有使用习惯。固定“更多”继续可达全部功能。

当前仅保持一台 iPhone 模拟器与一个 Mac Debug 客户端运行，另以独立浏览器上下文模拟成员，不同时启动多台模拟器。
