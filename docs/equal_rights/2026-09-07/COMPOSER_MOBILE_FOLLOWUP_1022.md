## 展开 Agent 入口变为完整协作入口

复核发现先前展开页未传入 `onAgent`，只使用默认的 Agent 提及选择器。现在会话通过 `_openComposerAgent` 接入与普通工具栏一致的真实协作面板，包括当前 Agent、邀请、分派任务、人格与参与、工作记录，以及宿主提供时的商店入口。

返回提及会合并入展开编辑器当前草稿，保留其正在编辑的正文、标题和格式；点关闭只是回到展开编辑器，不发送消息。编辑器收到选中 ID 后才显示明确提及，最终仍走会话统一发送通路。

工作记录或商店属于导航动作，因此必须先校验并保存展开草稿、关闭编辑器，等待父会话应用草稿，再执行导航。标题／正文长度或格式片段超限时返回失败，导航不会绕过草稿校验。回调期间仍校验身份代次、端点和会话；切换身份后旧内容清空，迟到提及不能写入新身份。协作面板在前台时，底层编辑器保留防重复状态而不持续显示加载动画。
