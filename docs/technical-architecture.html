ACTIVE AGENT / ARCHITECTURE

主动式智能体技术架构

持续感知群聊与任务上下文，以可恢复 Mission 为中心积累证据，在合适时机选择沉默、通知、完成或提出受控动作。它不是一个定时聊天机器人，而是一套带状态、策略、审批与审计的长期运行时。

一次主动循环

已实现
01摄取消息使用 IM 原始 event_id 幂等保存。
02关联证据匹配活跃 Mission，形成 evidence。
03等待时机连续聊天重置安静窗口，避免抢话。
04主动评估只检查新增证据；定时不等于发言。
05策略闸门高风险进入审批，低置信度保持沉默。
06可靠输出写入 outbox，平台发送后回写状态。

核心状态

Event → Evidence原始事实保持不可变，相关性单独表达。
Mission → Decision目标持续存在，每次判断记录理由。
Approval → Outbox授权和消息交付都可恢复、可重试、可审计。
MVP 使用 SQLite；生产多实例迁移 PostgreSQL，并用数据库租约避免任务重复执行。

安全与治理边界

提示与权限分离模型文本不能扩大工具权限。
高风险必须审批交易、付款、删除、资源变更、团队委派。
凭据不进上下文密钥仅存在本机忽略的环境文件。
全链路可解释证据、决策、批准者和发送状态均留痕。
